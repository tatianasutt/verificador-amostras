Verificador Inteligente de Amostras

Checklist simulado para conferência inicial de uma amostra de hemograma.

Aviso: este protótipo é apenas educativo. Não decide a aceitação ou rejeição de amostras reais, não substitui o POP vigente do laboratório e exige revisão humana. Use somente exemplos fictícios.

Conferência simulada

Não digite nomes nem dados de pacientes.
Para este exemplo: sangue total com EDTA para hemograma.

Fonte técnica

Base demonstrativa: POP.UDIDE.043, versão 1 (2025), do Hospital Universitário Ana Bezerra/UFRN-EBSERH, que apresenta critérios de rejeição/restrição específicos por exame. Para hemograma, o documento cita anticoagulante inadequado, coágulo, hemólise e volume insuficiente como critérios de rejeição.

Abrir o procedimento institucional (PDF)

Versão demonstrativa. Os critérios do documento consultado pertencem a um procedimento institucional específico e não devem ser generalizados para todos os laboratórios. Em caso de dúvida: “Não determinável com os dados fornecidos. É necessária uma revisão humana.”
